编排迁移 SQL

同一任务中的 SQL 会按从上到下的顺序逐条执行。全部 SQL 的结构校验通过后，才会写入第一批数据。
归档会删除源数据 归档表必须已由 DBA 建好且与源表结构相同。请在停写或维护窗口执行，并先完成数据库备份。
主业务表可配置多张主表；每张主表都是一棵归档关系树的根，按配置顺序依次执行。
关联从业务表每张从表必须选择某张主表或另一张从表作为上级，形成无循环的有向关系。
创建后不会立即写库 请在下方任务列表中再次点击“启动”，便于最后核对。
