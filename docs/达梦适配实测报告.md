# 达梦适配实测报告

验证日期：2026-10-22。测试使用用户提供的达梦实例，数据库产品 `DM DBMS`，服务端版本 `8.1.2.113`，驱动 `DmJdbcDriver18 8.1.3.140`，JDK `1.8.0_401`。

## 验证结果

| 场景 | 结果 |
|---|---|
| 默认模式与显式 Schema 建连 | 均成功；`SELECT 1 FROM DUAL` 通过 |
| 普通流式迁移、ID 游标分页迁移 | 各迁移 5 行；核对小数、中文、时间值 |
| 显式模式名和不带模式名的目标表 | 元数据定位及迁移均成功 |
| 主键及次唯一键重复跳过 | 目标保留原记录，后续正常记录写入；实测重复码 `-6602`，SQLState `23000` |
| 严格插入冲突 | 任务按预期失败，当前批次回滚，目标仅保留原有 1 行 |
| IDENTITY 迁移 | 自增种子 100 的目标表仍保留源 ID 1～5 |
| CLOB/BLOB/NULL | 12000 字符中文 CLOB、二进制及空值往返一致 |
| 缺表结构建议 | 任务按预期失败，生成含全部源列的候选 CREATE TABLE；未执行建议脚本 |
| 父子表归档冲突 | 子归档表重复时，主归档写入一并回滚，源主/子表各保留 3 行 |
| 父子表归档成功 | 主、子归档表各写入 2 行，源表各保留条件外 1 行；验证 IDENTITY 原值、跨批次切表及无游标子表主键分页 |
| 清理 | 每轮成功创建的专用表全部 DROP，ALL_TABLES 残留数 0；详细轮次见下文 |
| 应用启动与页面/API | 直接 classpath 启动成功，`GET /api/system` 返回 MYSQL、ORACLE、DM；源/目标下拉均有 DM |

本次实际只读/读写范围为随机前缀 `LDM_DM_*` 的专用测试表，未修改业务表。测试过程包含预期的冲突失败和缺表失败；最终主程序返回码 0、输出 `DAMENG_INTEGRATION_CHECK_PASSED`，清理校验成功。

当前验证覆盖 DM 到 DM；MySQL/Oracle 与 DM 的真实跨库组合、其他服务端版本、大规模数据性能和完整发布包尚未验证。Java 使用逐文件 JDK 8 `javac` 检查，未执行 Maven 编译或重新打包。原 MySQL/Oracle 实测报告维持原历史范围。

| 轮次 | 测试表前缀 | 表数 | 结果 |
|---|---|---:|---|
| 初始常规验证 | `LDM_DM_C880894C` | 9 | 常规迁移、重复键及普通父子归档全部通过 |

以上各轮均在 finally 中清理全部自己创建成功的表，并通过 ALL_TABLES 校验残留数为 0，共创建/删除 57 张不同名字的专用表。中间失败未进入业务表操作。最终兼容范围只忽略 DM 派生查询对可空性的弱化标记；物理源/归档表仍严格同构，查询字段类型、精度、标度及键空值检查保留。

本地检查还包括达梦连接配置和 SQL 隔离检查、原有数值范围/结构汇总/归档关系检查、15 秒连接看门狗，以及全部四项 JavaScript 检查；均通过。

## 检查程序与命令

实际执行入口为 `src/test/java/com/hundsun/lightdbmigration/DamengIntegrationCheck.java`。程序按顺序建连，连接失败即阻断后续尝试；只追踪和删除自己成功创建的表。

本次各轮均使用下列命令，连接环境变量中的实例地址、用户和密码仅在当前进程设置，运行后清除；本文使用占位符，不在仓库保存凭据。

```powershell
$env:LDM_TEST_DM_HOST = '<测试地址>'
$env:LDM_TEST_DM_PORT = '5236'
$env:LDM_TEST_DM_USER = '<测试用户>'
$env:LDM_TEST_DM_PASSWORD = '<从现场安全提供>'
$env:LDM_TEST_DM_SCHEMA = '<测试模式>'
java '-Dfile.encoding=UTF-8' -cp 'target/dm-check/classes;target/classes;target/dm-check/lib/*' com.hundsun.lightdbmigration.DamengIntegrationCheck
```

`target/dm-check/classes` 为本次修改/检查文件逐个 `javac -encoding UTF-8 -source 8 -target 8` 的输出；`target/classes` 提供已有未修改类；`lib` 复用本机既有应用依赖，加上校验过 Maven Central SHA1 的 DM 驱动。原始完整执行日志保存在本机 `target/dm-check/dameng-integration.log`，不进入 Git。

本地启动与 HTTP 验证命令为：

```powershell
java '-Dfile.encoding=UTF-8' -cp 'target/dm-check/classes;src/main/resources;target/classes;target/dm-check/lib/*' com.hundsun.lightdbmigration.LightDbMigrationApplication --server.port=18092 --server.address=127.0.0.1 --lightdb.config-store.directory=target/dm-check/server-data
Invoke-RestMethod -Uri http://127.0.0.1:18092/api/system
Invoke-WebRequest -Uri http://127.0.0.1:18092/ -UseBasicParsing
Invoke-WebRequest -Uri http://127.0.0.1:18092/app.js -UseBasicParsing
```

验证结束后已停止本次启动的服务。无远程服务器 Shell 命令。
