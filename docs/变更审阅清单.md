## 一、实现范围

- 新建 JDK 8 Spring Boot 单 Jar 服务。
- 新建离线 HTML/CSS/JavaScript 操作页面。
- 支持 MySQL、Oracle、达梦动态连接测试。
- 支持多 SQL 顺序迁移、结构预校验、流式分批，以及页面指定任意可比较类型的递增唯一游标分页。
- 支持默认跳过重复、严格插入、多个任务、暂停、继续、终止、进度和任务日志。
- 新增 Windows/Linux 启动脚本和现场实施操作手册。
- 新增不含凭据的现场隔离集成检查和 JDBC 连接看门狗检查。
- 修正跨库数值结构预检：固定整数目标按真实上下界校验，声明容量不能证明安全时合并检查本次查询的实际范围。
- 结构预检改为一次性汇总当前步骤及后续 SQL 的全部问题，并生成可复制、下载的目标表结构同步建议脚本。
- 最近一次两端数据库配置（含密码）使用 AES-GCM 加密保存，服务重启后页面自动回填，并支持页面主动保存和清除。
- Windows/Linux 启动脚本支持首参数指定服务端口。
- 每个成功提交的迁移批次记录批次总耗时及目标写入、提交耗时，便于现场区分源端读取与目标端写入瓶颈。
- Maven `package` 阶段自动生成完整现场交付 ZIP，统一收纳可执行 Jar、README、Windows/Linux 启动脚本和完整文档目录。
- 新增同库归档模式：一个任务支持多张主业务表，各自主表条件定义范围，子表通过字段映射关联所选父节点，全部归档成功后按子表先于主表的顺序清理源记录。
- 从表支持选择任一主表或另一张从表作为直接上级，形成以多个 `MAIN_n` 为根、单上级、可分支的有向无环森林；请求顺序可乱序，后端执行父节点优先拓扑排序。
- 归档关系在连接数据库前拒绝重复节点、上级缺失、自关联和循环；当前不支持一个节点同时关联多个上级。
- 归档每个主表批次使用一个本地事务，归档侧先主后子、源侧先子后主，严格校验写入数、删除数和关联残留。
- 归档强制严格插入；目标重复键、删除数量异常或任一子表失败均回滚当前主表批次。
- 归档主表和从表的唯一游标字段允许留空：填写时视为递增唯一键并执行固定上界 Keyset；留空时完整主键（支持任意列数的复合主键）只作为稳定排序和精确删除键，每批删除后重新读取当前首批，不假定主键递增。无主键表要求手工填写。
- 归档具体执行 SQL 只写入 SLF4J 后台日志，不加入任务详情日志，前端页面不展示；参数化查询记录绑定参数，JDBC batch 写入记录 SQL 模板与批量行数。
- 新增浏览器本地配置导入/导出，导出当前模式的迁移或归档规则；不携带数据库连接，不恢复任务执行状态，归档删除需现场重新确认。

## 二、数据表改动

无持久化表结构变更。工具不会自动创建或修改业务表；只有用户明确创建并启动归档任务后，才按配置删除已经成功写入归档表的源记录。

集成测试只使用本次专用测试表；测试完成后按精确表名删除，实际表名和清理结果记录在测试报告中。

## 三、业务参数改动

无既有业务参数改动。工具内置运行边界如下：

| 参数 | 默认值/上限 | 说明 |
|---|---:|---|
| 服务端口 | 默认 8088 | `start.bat <端口>` / `start.sh <端口>` 可指定；也支持 `SERVER_PORT` |
| 配置目录 | `data` | 可用 `LIGHTDB_DATA_DIR` 指定；保存密文和本机密钥，Git 忽略 |
| 默认批次 | 1000 | 页面可调整 |
| 批次范围 | 1～10000 | 防止误填造成过大内存或事务 |
| 归档批次范围 | 1～500 | 限制关联参数、SQL 长度和单批事务规模 |
| 主业务表数量 | 1～任务表总上限 | 多张主表按页面顺序执行，各自主表批次独立提交 |
| 从表复合关联字段 | 每表最多 5 组 | 仅支持本表字段与所选直接上级表字段的等值关联 |
| 归档唯一游标字段 | 可留空 | 填写时启用固定上界 Keyset；留空时完整主键仅用于排序和精确删除，支持随机 UUID 与任意列数的复合主键；无主键必须手工填写 |
| 归档删除确认 | 必须为 true | 页面勾选并在启动时二次确认 |
| 最大并发任务 | 4 | 其余任务排队 |
| 单任务最大 SQL 数 | 50 | 第一版保护上限 |
| 内存任务上限 | 100 | 已结束旧任务可自动清理 |
| 单任务页面日志 | 5000 条 | 环形保留 |
| 数据库连接看门狗 | 15 秒 | 驱动自身超时失效时避免任务永久卡住 |

## 四、接口定义

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/system` | 查看服务版本和能力 |
| POST | `/api/connections/test` | 测试一套数据库配置 |
| GET | `/api/config/last` | 解密读取最近一次两端配置，禁止响应缓存 |
| POST | `/api/config/last` | 校验并加密保存当前两端配置 |
| DELETE | `/api/config/last` | 删除最近配置密文和密钥 |
| POST | `/api/tasks` | 创建但不启动迁移或归档任务 |
| GET | `/api/tasks` | 查询任务列表和进度 |
| GET | `/api/tasks/{id}` | 查询任务详情及增量日志 |
| POST | `/api/tasks/{id}/start` | 启动任务 |
| POST | `/api/tasks/{id}/pause` | 请求批次边界暂停 |
| POST | `/api/tasks/{id}/resume` | 继续暂停任务 |
| POST | `/api/tasks/{id}/terminate` | 终止任务并取消当前 JDBC 操作 |
| DELETE | `/api/tasks/{id}` | 清除已结束或未启动任务的内存记录 |

`POST /api/tasks` 新增可选 `taskType`；缺省为 `MIGRATION`，归档使用 `ARCHIVE`。归档请求使用 `archive.mainTables[]`、`archive.childTables[].nodeId/parentNodeId/relations` 和 `archive.confirmSourceDelete`。旧请求仅传 `archive.mainTable` 时自动转换为单元素主表集合；单主表旧从表未填写上级时仍默认关联 `MAIN`，多主表时必须明确上级。任务快照新增 `taskType`，步骤进度新增 `nodeId`、`parentNodeId`、`sourceTable`、`deletedRows`；既有迁移请求保持兼容。

## 五、数据字典改动

无既有系统数据字典改动。工具使用以下固定枚举：

- 数据库类型：`MYSQL`、`ORACLE`、`DM`。
- Oracle 连接方式：`SERVICE`、`SID`。
- 写入方式：`IGNORE_DUPLICATE`、`STRICT_INSERT`。
- 任务类型：`MIGRATION`、`ARCHIVE`。
- 任务状态：`CREATED`、`QUEUED`、`VALIDATING`、`RUNNING`、`PAUSING`、`PAUSED`、`STOPPING`、`TERMINATED`、`SUCCEEDED`、`FAILED`。

## 六、查询模板改动

无既有业务查询模板改动。迁移查询由现场人员在页面按任务输入，创建任务后保存在服务内存中，也可由用户主动导出到规则 JSON 文件；最近数据库连接配置另行加密落盘，不包含查询 SQL。

工具内部会基于输入查询生成结构探测、总数统计和游标分页包装 SQL，不会把这些 SQL 保存到业务数据库；归档执行时会把具体 SQL 和受控参数摘要仅打印到后台日志。

归档模式包含两类运行期查询模板：填写游标时执行主表/从表固定上界 Keyset；留空时读取完整主键元数据，按全部主键列排序限制批量读取当前首批，使用参数化主键元组精确删除后重复执行且不生成 `MAX / > / <=`。两种模式都使用参数化从表关联、批量键删除及下级残留统计，关联值不直接拼入 SQL。

数值兼容修复后，若源数值声明范围可能超过目标固定整数类型，总数统计会在同一条 SQL 中按需合并 `MIN/MAX` 和非整数值数量，不会按字段循环执行 SQL。

配置游标时，同一条总数统计会合并 `COUNT(游标)` 和 `COUNT(DISTINCT 游标)`，一次扫描检查非空与唯一性。工具不检查 JDBC 数值类型或数据库自增标记。

## 七、DAO 层改动

无 DAO 接口、DAO 实现类或 MyBatis 映射。项目直接使用标准 JDBC，并保证正常路径不在逐行循环中执行 SQL：

- 普通模式：单次流式查询，按批次写入。
- 游标模式：每批执行一次带页面指定游标范围的查询。
- 目标写入：使用 JDBC Batch；Oracle 只有在批量重复键异常时才回退逐行识别。
- 归档：多张主表按顺序执行；每个主表批次只查询其关系树内的子表，主/子归档写入使用 JDBC Batch，源删除使用批量键 `IN`。

## 八、脚本改动

- `pom.xml`：增加 Maven Assembly Plugin，并把交付 ZIP 生成绑定到 `package` 阶段。
- `src/assembly/distribution.xml`：新增交付物装配清单，明确 Jar、README、启动脚本、文档目录及 Linux 脚本权限。
- `start.bat`：Windows 启动、Jar 检查、首参数端口校验和浏览器打开。
- `start.sh`：Linux 前台启动和首参数端口校验。
- `LiveDatabaseIntegrationCheck.java`：开发侧现场隔离测试程序，仅从进程环境读取测试连接信息。
- `DatabaseSupportTimeoutCheck.java`：模拟不响应中断的 JDBC 驱动，验证 15 秒应用级连接看门狗。
- `NumericCompatibilityCheck.java`：无数据库数值边界回归，覆盖 `NUMBER(20,0) -> BIGINT`、同位数范围差异、`MEDIUMINT` 和小数写整数。
- `StructureValidationAggregationCheck.java`：验证多字段、多步骤问题汇总、MySQL/Oracle 表结构同步建议脚本、VARCHAR 应用游标的页面配置认可，以及批次日志同时包含总耗时和目标写入提交耗时。
- `LastDatabaseConfigStoreCheck.java`：验证密码密文、重启式重载和密钥/密文清除。
- `ArchiveEngineIntegrationCheck.java`：验证专用表事前不存在、同任务多主表、前端任务日志不暴露 SQL、显式游标 Keyset、空游标非 Keyset、随机 UUID 单列主键、主表与多级子表三列复合主键、严格重复回滚、多级从表关系、外键顺序、保留数据和最终清理。复合主键实现按元数据列集合动态生成，不限制为三列。
- `ArchiveCompositePrimaryKeyIntegrationCheck.java`：在不依赖外键权限的测试库中验证三列复合主键主表、四列复合主键子表、三列父子关联、批量主键元组删除、保留数据和最终清理。
- `ArchiveGraphValidationCheck.java`：无数据库验证旧单主表兼容、多主表及从表归属、空游标请求可创建、乱序节点拓扑排序、循环关系拒绝和上级缺失拒绝。
- `AppDomSelectorCheck.js`：验证普通迁移步骤只从 `#stepsContainer` 读取，避免隐藏的归档卡片被误当成迁移 SQL 并触发空元素访问。
- `ArchiveMultiMainDomCheck.js`：验证主表动态模板、添加/删除、多主表请求收集和从表上级节点来源。
- 运行时同步脚本：只在内存和任务详情中生成，不落盘、不自动执行、不包含 `DROP COLUMN`。
- 无数据库升级脚本、存储过程或业务初始化脚本。

执行 `mvn clean package -DskipTests` 后同时生成 `target/light-db-migration.jar` 和 `target/light-db-migration-<项目版本>.zip`，不再需要手工组装发布目录。

## 九、日志与安全

- 关键连接、结构校验、分页方式、批次完成、任务控制和异常节点均记录日志；批次完成日志新增总耗时及目标写入、提交耗时。
- 前端任务日志记录同库事务边界、预计主/子表行数、每个主批次写入/删除数量、子表合计和回滚原因，但不包含具体 SQL。
- SLF4J 后台日志额外记录实际执行 SQL；查询及删除记录最多前 50 个绑定参数，超长文本截断、二进制只记长度，批量插入不逐行展开完整业务字段值。
- 当前项目不存在统一的 `LoggerUtils` 工具，因此后端使用 Spring Boot 自带 SLF4J。
- 数据库密码不写明文文件、不进入任务日志或普通任务接口；最近配置接口按需求返回密码且禁止缓存，任务结束、删除或服务退出时清空任务内存密码字段。
- `data/` 已加入 `.gitignore`。密钥与密文同机保存，依赖现场操作系统目录权限，不作为公网多用户凭据保险库。
- 规则 JSON 仅白名单保存当前模式的配置，连接字段始终排除；文件中的 SQL、表名和业务条件仍为明文，交付前需要审阅。
