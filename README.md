# Light DB Migration

面向现场实施人员的轻量级 MySQL/Oracle 数据迁移与同库归档工具。服务启动后，数据库配置、迁移/归档规则、批次大小、任务控制、进度和日志全部在浏览器页面中操作。最近一次数据库配置（含密码）使用 AES-GCM 加密保存在服务本机，重启后自动回填，且不会进入日志。

## 主要能力

- JDK 8 单 Jar 服务，无需安装前端运行环境。
- 支持 MySQL、Oracle 之间同构或跨库迁移，不使用存储过程。
- 支持同库数据归档：将主业务表选定数据写入同结构归档表，并在批次成功后删除对应源记录。
- 支持多级关联从表；每张从表可选择主表或另一张从表作为上级，并配置“本表字段=上级表字段”，形成单上级、可分支的有向无环关系。
- 归档每批严格按“父节点到子节点写归档表 → 子节点到父节点清理源表 → 提交”递归执行，任一节点失败都会回滚当前主表批次。
- 一个任务支持多条查询 SQL，先整体校验结构，再按顺序逐条迁移。
- 结构预检一次性汇总全部步骤的问题；失败后可在页面复制或下载目标表结构同步建议脚本。
- 普通查询采用流式读取；页面可指定任意类型的递增唯一字段启用带上界的游标分页，不依赖数据库自增标记。
- 默认跳过重复数据；MySQL 使用 `INSERT IGNORE`，Oracle 优先使用主键/唯一键 `MERGE`。
- 支持多个任务、批次级进度和耗时、网页日志，以及暂停、继续、终止。
- 每个任务使用独立数据库配置；任务状态在服务重启后清空，最近一次数据库配置可自动恢复或在页面主动清除。

## 开发打包

项目使用 Maven 管理依赖，打包环境要求 JDK 8 和 Maven 3.6.3 及以上版本。开发人员执行一次命令即可同时生成可执行 Jar 和现场交付 ZIP：

```text
mvn clean package -DskipTests
```

生成文件：

- `target/light-db-migration.jar`：可执行服务。
- `target/light-db-migration-<项目版本>.zip`：完整现场交付包，包含 Jar、README、Windows/Linux 启动脚本及完整 `docs` 文档目录。

不需要再手工复制文件或二次压缩。

现场人员不需要 Maven，只需 64 位 JDK 8、发布 Jar 和启动脚本。完整说明见 [现场实施操作手册](docs/现场实施操作手册.md)，本次真实数据库验证见 [现场实测报告](docs/现场实测报告.md)，架构和核心实现见 [开发人员设计说明](docs/开发人员设计说明.md)。

## 启动地址

- Windows：`start.bat 18088`；Linux：`./start.sh 18088`。端口参数省略时默认使用 `8088`。
- 页面：`http://127.0.0.1:<启动端口>`
- 应用日志：`logs/light-db-migration.log`
- 加密配置：`data/last-database-config.dat`，密钥为同目录 `last-config.key`；`data/` 不进入 Git。

## 数据归档安全边界

- 归档只允许在一个数据库连接内完成，不支持跨库删除源数据。
- 主表查询必须返回源表全部字段；主表和每张子表都必须配置在归档范围内非空、唯一、递增的游标字段。
- 从表关系不允许上级节点不存在、自关联或循环；一个从表节点只允许选择一个直接上级节点，但一个节点可以关联多张下级从表。
- 归档表必须提前创建且与对应源表结构相同；归档使用严格插入，目标重复键会导致当前批次回滚，不会忽略重复后删除源数据。
- 正式执行前必须完成备份并安排停写或维护窗口；工具按批次提交，不提供已提交批次的自动恢复。

## 当前边界

- 工具不会自动执行建表或改表；结构校验失败时只生成需要人工审核的目标表结构同步建议脚本。
- 不支持存储过程、SQL 占位参数、任务断点持久化和执行后自动恢复。
- 暂停、终止按当前数据库操作或批次边界生效；已经提交的批次不会自动回滚。
